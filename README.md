# vibelabsmc-website

**[vibelabsmc.org](https://vibelabsmc.org)** is under construction. This `main` branch only
serves the under-construction page in `public/`, deployed to GitHub Pages on every push.

The full docs site (SvelteKit) is built on the **`develop`** branch:

```bash
git clone https://github.com/vibeLABS-MC/vibelabsmc-website.git
cd vibelabsmc-website
git switch develop
```

Read `CLAUDE.md` and `CONTRIBUTING.md` on `develop` before you start. To launch, merge `develop`
into `main`; the merge replaces this page and its workflow with the full site.
